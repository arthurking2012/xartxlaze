# ფარსმან ხარხალი — ლიტერატურისა და მწერლობის განვითარება

ისტორიული ქრონიკის ვებ-გვერდი ქართული ტიპოგრაფიითა და ინტერაქტიული ფუნქციონალით.

## ფუნქციები
- 📜 ავთენტური ქართული ტიპოგრაფია (`Noto Serif Georgian`, `Noto Sans Georgian`)
- 🎨 თემის შეცვლა (მუქი / პერგამენტის სტილი)
- 📋 ტექსტის ერთი დაწკაპუნებით კოპირება
- 📱 სრულიად მორგებული მობილურ და დესკტოპ ეკრანებზე

## GitHub Pages-ზე გაშვება
1. ატვირთეთ ფაილები თქვენს GitHub რეპოზიტორიაში.
2. გადადით რეპოზიტორიის **Settings** -> **Pages**.
3. **Branch** ველში აირჩიეთ `main` (ან `master`) და დააჭირეთ **Save**.
4. საიტი რამდენიმე წამში გაეშვება პირდაპირ ბმულზე!
